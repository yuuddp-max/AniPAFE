# 投票明細・感想の検索

運営管理の「投票明細・感想を開く」に検索欄を追加。

- 作品名・投票者名・ニコニコID・感想・動画IDの部分一致検索。
- 部門と「感想ありのみ」を組み合わせ、検索ボタンまたはEnterで適用。
- 条件変更時は先頭ページに戻る。条件クリアで全明細を表示。
- DBで全明細を検索し、一致件数と現在の50件だけを返す。検索中・再試行・0件表示に対応。
- キーワードは200文字以内。全角英数字等をNFKCで正規化し、大文字小文字を区別しない。`%`や`_`も文字として検索する。
- 感想の空白・改行・全角スペースだけの行は「感想あり」から除外。

検索用RPCはSECURITY INVOKERで動作し、既存の管理者確認と集計結果テーブルのRLSを使用する。集計版・日時・入力リビジョンを照合し、古い集計はAPIで409を返す。検索のないページ取得・CSV全件出力は従来の処理を使用する。

## 検証と反映

本番ビルド・型チェックが成功。検索と保存集計のDB単体テスト2件、関連E2E5件（初期取得・検索・明細ページ・年度切り替え・CSV・権限・再試行）が成功。合成フィクスチャ1,206明細を使い、全件参照と検索結果の件数・順序を照合した。

本番反映は `20261029112748_tally_detail_search.sql` を先に適用し、その後アプリをデプロイする。DB関数は本番へ適用済み（クラウドのマイグレーション番号と同期）。既存テーブル・集計データ・集計ルールの変更はない。
